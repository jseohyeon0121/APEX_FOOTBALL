# ⚽ APEX FOOTBALL (에이펙스 풋볼)

브라우저에서 바로 즐기는 3D 축구 게임. 내 구단을 창단하고 선수를 키워 리그와 컵대회 정상에 도전하세요.

## 🎮 게임 하러 가기
**👉 [https://jseohyeon0121.github.io/APEX_FOOTBALL/](https://jseohyeon0121.github.io/APEX_FOOTBALL/)**

- PC 브라우저(크롬 · 엣지 권장)와 키보드로 플레이해요.
- 계정 · 구단 데이터는 지금 쓰는 브라우저에만 저장돼요. 다른 기기나 브라우저에서는 새로 시작해야 해요.

## 🚀 시작하기
1. 인트로 화면에서 아무 키나 누르거나 화면을 클릭해요.
2. 회원가입 → 로그인 (이 브라우저 안에서만 쓰는 로컬 계정)
3. 팀 컬러와 구단 이름을 정해 **구단 창단** → 그 구단 선수 20명으로 시작해요.
4. 홈에서 리그 · APC 에펙컵 · 프리킥 연습 등을 골라 플레이해요.

## ⌨️ 조작법
| 키 | 동작 |
|---|---|
| 방향키 | 이동 |
| E / Shift | 스프린트(질주) |
| S | 짧은 패스 |
| Z + S | 긴 패스 |
| A | 로빙 패스 / 크로스 |
| W | 스루 패스 |
| Q + W | 로빙 스루 패스 |
| D | 슛 |
| Z + D | 감아차기 |
| F를 누른 채 D → D 한 번 더 | 파워슛 (게이지 시작 → 발사) |
| Tab | 조작 선수 바꾸기 |
| N | 이름표 켜기 / 끄기 |
| Space / Enter | 연출 넘기기 |
| Esc | 프리킥 연습 끝내기 |

- 패스 세기와 거리는 **게이지**로 정해져요. 오래 누를수록 멀리 가요.
- 공이 오기 전에 미리 누르면 다이렉트 슛 · 패스가 나가요. 잡고 찰 때보다 부정확하고, 발리 능력치가 높을수록 정확해요.
- 키 배치는 설정에서 바꿀 수 있어요.

## 🏆 게임 모드
- **리그 시즌** — 아마추어부터 APL까지 12단계 리그. 14경기를 치르고 순위에 따라 보상을 받아요. 직접 플레이하거나 빠른 진행(시뮬레이션)을 고를 수 있어요.
- **APC 에펙컵** — 강팀 8팀이 겨루는 토너먼트. 우승하면 세리머니와 큰 보상!
- **프리킥 연습** — 프리킥만 따로 연습할 수 있어요.

## 📈 선수 육성
- **훈련** → **훈련 돌파** (최대 10레벨) → **특훈** (훈련 10레벨부터)
- **강화** 1~10강 — 강화 카드를 넣어 확률로 도전해요. 연속 강화도 있어요.
- **한계 돌파** — 강화 상한(기본 5강)을 최대 10강까지 올려요.
- **상점**에서 훈련 · 강화 박스와 **BS 랜덤 선수팩**을 사고, **이적시장**에서 선수 정보를 볼 수 있어요.
